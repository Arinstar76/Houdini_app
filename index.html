제미나이 테두리 없이 '루비 아이콘'으로 추가하기

            
왜 gemini.google.com 링크는 제미나이 로고가 뜰까요?

          

        

        
      


      

        

          ⚠️ 원인: 제미나이 공유 링크(gemini.google.com)는 바깥 껍데기가 구글 제미나이 페이지라서, 그대로 홈에 추가하면 검은색 제미나이 상하단 바와 제미나이 로고가 박힙니다. 진짜 단독 웹앱(루비 로고 + 전체 화면)으로 등록하려면 아래 30초 무료 단독 주소 방법을 써보세요!
        


        

          
🐙 가장 깔끔한 정석: GitHub Pages로 나만의 고정 주소 만들기

          
    
            
  1. GitHub에서 새 저장소(Repository)를 만들고, 첨부된 압축 파일 안의 index.html 파일 1개를 업로드합니다.
    2. 
            
  2. 저장소의 Settings → Pages → Branch를 main으로 선택 후 Save를 누르면 https://아이디.github.io/저장소이름/ 주소가 평생 무료로 생성됩니다.
    3. 
            
  3. 이 주소를 아이폰 Safari에서 열고 공유(📤) → [홈 화면에 추가]를 누르면, 프로파일 설치 없이도 ChatGPT Sites와 100% 똑같이 루비 로고 + 전체 화면 + 기기 자동 저장이 완벽히 작동합니다!
    4. 
          

        


        

          
✅ 대안: 초간단 드래그 앤 드롭 호스팅

          
    
            
  1. 채팅창에 첨부된 kotsu_vex_ios.zip 카드를 눌러 아이폰 '파일(Files)' 앱에 저장한 뒤 터치해 압축을 풉니다 (houdini_vex_fx_lab.html 생성).
    2. 
            
  2. 사파리에서 무료 단일 HTML 호스팅인 Tiiny.host (또는 Netlify Drop)에 접속해 방금 푼 houdini_vex_fx_lab.html 파일 1개를 업로드합니다.
    3. 
            
  3. 즉시 만들어진 전용 주소(https://...tiiny.site)를 사파리에서 열고 하단 공유(📤) → [홈 화면에 추가]를 누르면, 제미나이 검은 화면 없이 100% '루비 아이콘'과 '코츠벡스' 이름으로 전체 화면 실행됩니다!
    4. 
          

        

      


      

        
🚀 호스팅 사이트 없이 아이폰에 '루비 아이콘' 즉시 설치 (Web Clip)

        

          무료 호스팅 사이트에 가입하거나 올릴 필요 없이, 아래 버튼(또는 채팅창의 kotsu_vex_installer.mobileconfig 파일)을 사파리에서 열면 아이폰 설정 → 프로파일 설치를 통해 제미나이 로고 없이 100% '루비 아이콘'과 전체 화면 앱으로 홈 화면에 바로 생성됩니다!
